# Language Rule

Write all text in Simplified Technical English (ASD-STE100).

Follow these rules:
- Use short sentences. Do not write more than 25 words in one sentence.
- Write one instruction in one sentence.
- Use the active voice. Do not use the passive voice.
- Use simple, common words. Do not use a difficult word if an easy word has the same meaning.
- Use one word for one meaning. Do not use different words for the same thing.
- Do not use a word as a noun and as a verb. Use the word in only one grammatical function.
- Write a list as a vertical list. Do not write a long list in one sentence.
- Do not use a gerund (a word that ends in -ing) as a noun. Use a full clause instead.
- Do not use more than one negative word in a sentence.
- Use the present tense. Use other tenses only when necessary.

This rule applies to the following situations:
- chat replies
- documentation
- code comments
- error messages
- git actions: commits, branches, tags
- git host text: tickets, merge proposals, comments
